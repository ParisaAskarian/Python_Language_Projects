# Python Projects

This repository branch contains the following projects:

- **Minesweeper:** A classic Minesweeper game.
- **Tic-Tac-Toe:** A two-player Tic-Tac-Toe game.
- **Restaurant Menu:** A restaurant menu application (currently under development).
- **Various Algorithms:** Implementations of several algorithms for solving different problems.

## Libraries Used

The following Python libraries are used in the Minesweeper game and Restaurant Menu project:

- **Tkinter:** Used to create and display the graphical user interface (GUI).
- **PIL (Pillow):** Used to load and display images in the applications.

## Project Status

Some projects are complete, while others are still under development.
